# Changelog

## v1.0.0 (2024-11-25)

### Features
- **ICS-style home screen** with search bar, multi-page workspace, and page indicator dots
- **Bottom dock** with Back, Phone, Browser, Email, Camera, Recents, and All Apps
- **App drawer** with real-time search/filter for all installed launcher apps
- **Configurable grid size** (4×4 to 5×6) via Settings
- **Dark theme** (holo-dark inspired palette)
- **Welcome screen** on first run

### Wallpaper System
- 3 bundled static wallpapers (ICS Cream Sandwich, ICS Android, ICS Blue)
- Live wallpaper service with Canvas-drawn Android robot on ice cream sandwich
- Parallax offset on page swipe
- Photo picker from gallery (scoped-storage compliant)

### Nexus-Era Apps (13 reimplemented)
Browser, Email, Gallery, Music, Camera, Calendar, Contacts, Clock, Calculator, Messaging, Notes, File Manager, Settings

### Easter Egg
Self-contained Android 4.0.4 Ice Cream Sandwich Easter egg activity

### Quick Settings
Panel with toggles for Wi-Fi, Bluetooth, Data Usage, Sound, Display, Battery, Location, Security, Accounts

### App Widget
Clock widget showing time and date

### Technical
- minSdk 29 (Android 10), targetSdk 36 (Android 16)
- No root, no custom recovery, no unlocked bootloader required
- No proprietary binaries bundled
- All original vector artwork
